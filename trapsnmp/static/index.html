Security profiles

User policy

Policy id username, encrypted with Basic256Sha256 unless the channel is already SignAndEncrypt. The first user is trapsnmp / trapsnmp.

Rejected clients

A secure client is rejected until its certificate is trusted. Trust moves it from data/pki/rejected to data/pki/trusted/certs.

Forward as a client

Each new trap is also written, as JSON, to a node on any OPC UA server that accepts anonymous access.
